# Diagrammi Mermaid

Cinque famiglie rese offline, con il tema OK-ia: tocca per ingrandire.

```mermaid
flowchart TD
    A[Report .md] --> B{md Viewer}
    B --> C[Lettura]
    B --> D[Presentazione]
    B --> E[Esportazioni]
    C --> F[Mermaid]
    C --> G[Mappe]
    E --> H[PDF]
    E --> I[Word]
    E --> J[PowerPoint]
```

Lo zoom a schermo intero mantiene il disegno vettoriale: i diagrammi restano nitidi a ogni scala.
